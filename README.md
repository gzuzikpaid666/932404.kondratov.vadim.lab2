Языковой энтузиаст и переводчик
Лабораторная работа №2, Вариант №17, представляющая собой персональную веб-страницу. Проект обновлен с выносом стилей во внешний файл style.css, использованием CSS-переменных и добавлением JavaScript для динамической смены темы оформления.

Содержание страницы
Шапка (<header>): Вадим Кондратов, профессия, бейдж квалификации и интерактивная кнопка-переключатель темы (#lang-switcher).

Навыки (<section>): Список ключевых компетенций (письменный и устный перевод, изучение языков, межкультурная коммуникация, CAT-инструменты).

Проекты (<section>): Список выполненных работ (перевод документации, подкаст, курс казахского языка, локализация приложений).

Изображение (<img>): Аватар / иллюстрация учебника казахского языка.

Форма обратной связи (<form>): Поля для ввода имени, email и сообщения с кнопкой отправки. Реализована градиентная обводка полей при фокусе.

Боковая панель (<aside>): Информация о цели обучения студентов казахскому языку.

Подвал (<footer>): Копирайт и год создания (© 2026 Вадим Кондратов).

Дизайн
Цветовая гамма:

Базовая: Бирюзово-белая (--main-color: #0e7490, --accent-color: #ffffff).

Активная тема (Франция): Сине-красная (#0055a4 / #ef4135).

Стилизация: Все CSS-стили вынесены во внешний файл style.css. Использованы CSS-переменные в :root, Flexbox-верстка, псевдоклассы (:hover, :focus, :active, :visited), плавные переходы (transition) и градиентные рамки при фокусе (border-image: linear-gradient).

Интерактивность
Переключение темы на JavaScript: Динамическая смена CSS-переменных при наведении мыши или фокусе (mouseenter, mouseleave, focus, blur) на элементе переключателя с использованием style.setProperty() и style.removeProperty().

Технологии
HTML5 (семантические теги: header, main, section, aside, footer)

CSS3 (внешняя таблица стилей, CSS Custom Properties, Flexbox, анимации transition, border-image)

JavaScript (Vanilla JS) (управление DOM, динамическое изменение CSS-переменных, обработка событий)
